# Лабораторная работа №1. Прокат видеодисков

**Дисциплина:** Распределённые вычисления и приложения  
**Автор:** Андрианова Есения, группа ПИбд-41  
**Вариант:** 3 - Учёт посетителей в прокате

Данное приложение служит для автоматизации работы пункта проката видеодисков.
Реализует учёт посетителей и выдачу дисков на руки.

### Функциональные возможности:

- **Добавление посетителя** - регистрация нового клиента проката с указанием ФИО и телефона.
- **Прекращение отношений с посетителем** - перевод клиента в статус `INACTIVE`.
- **Редактирование записи о посетителе** - изменение ФИО, телефона, статуса и признака наличия диска.
- **Выдача диска на руки** - установка флага `hasDisk = true`, означающего, что посетитель сейчас держит диск.
- **Формирование отчёта** - сводка по прокату:
  - сколько посетителей **сейчас держат диски на руках**;
  - сколько **всего посетителей зарегистрировано** в прокате.
